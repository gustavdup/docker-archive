Back up: copy to the drive, project stays in Docker. Archive: copy, then remove from Docker to free the space.

Each project is copied to the drive and checked. When that succeeds, the project is removed from Docker (containers, volumes and images). The archive on the drive becomes the only copy. You can restore it any time from the Archives tab. If any check fails, the project stays in Docker.

Claude Code skill

Lets Claude Code restore an archived project when you ask it to start one.

Checking…
  1. Before starting a compose project, Claude runs ensure . in the project folder.
  2. If the project was archived, it is restored and the copy stays on the drive. Otherwise nothing happens.
  3. If the drive isn't connected, Claude asks you to connect it instead of starting the project with empty volumes.

The skill only restores. It never backs up, archives, removes from Docker or deletes copies.
